# Installing Nous

## For end users (non-technical)

1. Download Nous Setup.exe
2. Double-click to install
3. Click Next, Next, Install
4. Nous opens automatically
5. Follow the setup wizard

That's it. No Python needed.
No terminal. No configuration.

## First time setup

On first launch Nous will ask for:
- Your Anthropic API key
  (get one free at console.anthropic.com)
- Your industry type
- Privacy preferences

Setup takes 2 minutes.
